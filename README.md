🐦 Zwitscher

Zwitscher ist eine Fullstack-Microblogging-App zum Teilen kurzer Gedanken. Nutzer können Beiträge veröffentlichen, andere Beiträge liken und die Profile ihrer Autoren entdecken.

Funktionen

- Registrierung und Anmeldung mit JWT-Authentifizierung

- Chronologischer Feed mit den neuesten Beiträgen zuerst

- Eigene Beiträge erstellen, bearbeiten und löschen

- Beiträge liken und gelikte Beiträge gesammelt anzeigen

- Profilseiten mit den Beiträgen einzelner Nutzer

Technologien

Frontend: React, TypeScript, Vite, Tailwind CSS, DaisyUI und TanStack Query
Backend: C#, ASP.NET Core, Entity Framework Core und SQLite

Die REST-API ist mit OpenAPI dokumentiert. Orval generiert daraus den typisierten API-Client für das Frontend.
